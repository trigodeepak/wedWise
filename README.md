# WedWise — Prepare for Forever (GitHub Pages Static Repository)

## 🎨 Brand Colour Palette
- **Deep Plum (`#70265F`)**: Primary brand color, wordmark, headings, primary buttons
- **Muted Rose (`#B17A9E`)**: Secondary accents and dividers
- **Warm Marigold Gold (`#E6A04A`)**: Right infinity ribbon, golden heart dot on `i`, highlights
- **Soft Blush (`#F9EDEF`)**: Section backgrounds, pill badges, and card highlights
- **Warm Cream (`#FFF9F2`)**: Main page canvas background

## 📁 Repository Files
- **`config.json`** — **Single Source of Truth**: Update onboarded `experts`, `quizQuestions`, `reviews`, `faqs`, `courses`, `prompts`, `plans`, and `whatsappNumber` directly in this file.
- **`index.html` & `counseling.html`** — Customer-facing Bootstrap 5.3 pages.
- **`styles.css` & `script.js`** — Theme tokens and null-safe modular logic.
- **`assets/`** — Includes `wedwise_logo_horizontal.jpg`, `wedwise_logo_square_dp.jpg` (Instagram/WhatsApp DP), `wedwise_logo_circle_dp.jpg` (Profile Picture), and `wedwise_couple.jpg`.
